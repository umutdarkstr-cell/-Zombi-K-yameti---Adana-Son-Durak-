# -Zombi-K-yameti---Adana-Son-Durak-
OMBİ KIYAMETİ: ADANA - SON DURAK 🧟‍♂️
Adana'da geçen, tamamen metin tabanlı, Türkçe bir hayatta kalma RPG oyunu.

Tarih: 2 Kasım 2026. Seyhan Nehri kırmızı akıyor. Radyo sustu. Sen Çukurova Devlet Hastanesi'nde gözlerini açtın...

Oyun Ekran Görüntüsü

🎮 Özellikler
13 Farklı Bölge: Çukurova Hastanesi, Büyük Saat, Tepebağ, Kapalı Çarşı, Tren Garı, İncirlik Üssü, Seyhan Barajı...
6 Zombi Türü: Yürüyen, Koşucu, Şişkin (patlayan), Gölge, Zırhlı Çevik Kuvvet, Bağıran (sürü çağıran)
Hayatta Kalma Sistemi: Açlık, susuzluk, can, moral ve enfeksiyon
Sistemler: Envanter, loot, craft (molotof, şalgam suyu), dinlenme, kayıt/yükleme
Hikaye: Görevler, NPC'ler (Ayşe Teyze, Kebapçı Mesut) ve 3 farklı final
Saf Node.js: Hiçbir dış kütüphane gerektirmez
🚀 Nasıl Oynanır?
Node.js kurulu olmalı (https://nodejs.org)
Repoyu indir:
git clone https://github.com/kullanici-adin/adana-zombi-kiyameti.git
cd adana-zombi-kiyameti
Çalıştır:
npm start
# veya
node index.js
ÖNEMLİ: Dosyaya çift tıklama! Terminalden çalıştır. Yoksa Windows wscript.exe ile açmaya çalışır ve antivirüs uyarı verir.

🎯 Komutlar
1 / git - Haritada hareket et
2 / envanter - Çantanı aç
3 / craft - Eşya üret
4 / dinlen - Uyu ve can topla
5 / kaydet - Oyunu kaydet
